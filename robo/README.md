# robo-avatar

A face for your AI: a small animated robot that shows what your product is doing.

Everything you need to know, with pictures, is on the project page: https://github.com/Hazenbox/Robo-avatar

```tsx
import { RoboAvatar } from "robo-avatar/react";

<RoboAvatar size={96} state="thinking" />;
```
