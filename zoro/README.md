# zoro-avatar

A face for your AI: a small animated robot that shows what your product is doing.

Everything you need to know, with pictures, is on the project page: https://github.com/Hazenbox/Zoro-avatar

```tsx
import { ZoroAvatar } from "zoro-avatar/react";

<ZoroAvatar size={96} state="thinking" />;
```
